Is Vyxo free to use?＋

Vyxo is designed with a useful free experience. Optional premium features can be introduced later without removing the essential community tools.

Does Vyxo need Administrator permission?＋

No. Grant only the permissions required by the features you enable. Keeping permissions minimal is safer for every server.

Where is server data stored?＋

Only data needed for enabled features should be stored. Review the published Privacy Policy for the categories, purpose and deletion process.

Can I disable individual features?＋

Yes. Vyxo is modular, so moderation, economy, tickets, music and other systems can be configured independently.

How do I request help or data deletion?＋

Use the support page or email vyxo.contact@gmail.com. Privacy requests may require reasonable verification.
